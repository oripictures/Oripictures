# Ori Pictures website

Static site for Ori Pictures. The deployable site lives in `dist/`.

## Run locally

```
node server.cjs
```

Then open http://127.0.0.1:4173.

## Files

- `dist/` – the site (HTML, CSS, JS, images)
- `DESIGN.md` – design notes and rules
- `server.cjs` – tiny local preview server
- `connect-email.cjs`, `download-photos.ps1`, `crop.ps1` – one-off helper scripts used while building

Sample photos in `dist/assets/` are from Unsplash and should be replaced with Ori's own portfolio before public promotion.
